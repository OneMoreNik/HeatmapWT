WT Route Heatmaps

A personal map-learning tool: historical heatmaps of where heavy, medium, light and tank-destroyer vehicles go on each map and layout, plus a replay view that follows one player's movements. Built from server replays; no live game data about enemies.

A1

Verdict

Feasible. The open-source parser wrpl-inspector (Go, AGPL-3, active August 2026) already pulls each vehicle's model and full-precision position track from a server replay. The server replay has every vehicle on both teams, about 30 per battle. Vehicle class and BR come from the community War Thunder Datamine. The hardest part is collecting enough battles for each map layout.

Follow a player

Yes, this is possible, and it is a cheap feature because the parser already groups positions by player and vehicle. Load a replay, pick anyone from either team, and see their full route, where they stopped and where they fired from. It reuses the same data as the heatmaps, so it can come right after the first proof of concept.

What the follow view shows

  • A player list for both teams with name, vehicles used and kills/deaths. Pick one or several players.
  • Each life as a separate segment. A respawn in a new vehicle starts a new segment with its own spawn marker.
  • Stops, detected automatically: places where the vehicle stayed within about 10 m for 15 s or more. Each one lists its time, grid square, and any kills made from there with range.
  • A timeline slider to replay the movement and see where they were at a given minute.
  • Later: follow the same player across many replays and cluster their stops into "positions this player uses on this map".

Limits

  • Turret or aim direction is probably not available for other players. We get position, kills and deaths.
  • Server replays may only be kept for a limited time. Download them soon after the battle and keep the files.
  • Keep per-player data local. It is for your own learning, not for publishing profiles of other players.
C3

What to bring

2–3 Ground RB replays, ideally on the same map

  1. In War Thunder, turn on replay autosave (Options → Main parameters → "Autosave replays", or similar).
  2. Play a few Ground RB battles.
  3. Copy the newest .wrpl files from the Replays folder inside the War Thunder install folder. On Steam this is usually steamapps\common\War Thunder\Replays.
  4. Note the map name and anything you remember: where you went, where you died. That is our accuracy check.

Your local replay is recorded from your client. We use the session ID inside it to download the full server replay, which has every vehicle.

D4

Build order

  1. Proof of concept. Parse one server replay and plot all tracks on the map image. Check against what you remember.
  2. Follow-a-player viewer for single replays.
  3. Pipeline: session IDs → download → parse to Parquet → add class and BR from the datamine → DuckDB.
  4. Heatmaps per map, layout, spawn side, class and BR band: route, stop and engagement layers, with battle and sample counts shown.
  5. Windows overlay: transparent click-through window, manual calibration, Ctrl+Q for the large map and Ctrl+E for the minimap. Needs borderless or windowed mode.
  6. Filters for BR, nation and vehicle; data confidence label.
E5

Rules and safety

Gaijin staff have said overlays using the game's local data are fine, while enemy markers can count as ESP and reading rendered frames or game memory is not allowed (forum thread, May 2024). This tool shows only precomputed historical data, never touches the game process, and does not capture the screen. Alignment uses manual calibration for that reason.
